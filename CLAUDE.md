# DeskBreak project rules

## Website

Any website or web page for DeskBreak must not look AI-generated ("vibe coded"). Follow these rules precisely.

### Never use

- Purple gradients
- Pill-shaped buttons
- Fake reviews, testimonials or customer quotes
- Fake metrics or fake customer counters
- Vague hero text; the headline must say plainly what the app does
- Emoji as icons
- Em dashes in copy
- Over-the-top scroll animations
- Cursor animations or custom cursor effects
- AI-generated stock-style photos
- Generic AI-sounding copy; write specific, plain sentences about what DeskBreak actually does

### Required before launch

Do not launch the site until all of these are done:

- [ ] A custom domain is connected
- [ ] A favicon is added
- [ ] Any "Made with AI" (or similar builder) tag is removed
- [ ] A privacy policy page exists
- [ ] A terms and conditions page exists
