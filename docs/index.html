macOS menu bar app

Reminds you to drink water every hour and walk every two hours.

DeskBreak counts only the time you are actually using your Mac. Each reminder asks for an answer, and every answer is written to a log on your Mac.

Install with Homebrew Read the source

Requires macOS 13 (Ventura) or later.

How it works

Counts active time only

Timers freeze while your Mac sleeps and pause while the screen is locked or you have not touched the keyboard or mouse for 15 minutes.

Asks for an answer

Each reminder is a small silent panel in the top-right corner with three buttons right underneath: I did, Not doing, or Remind me in 15 min. It never takes keyboard focus, so you can keep typing.

Keeps a log

Every reminder is recorded as done, skipped or missed in a readable JSON file. Entries older than 60 days are removed.

Nothing leaves your Mac

DeskBreak has no account, no analytics and no network code. It needs no special permissions. To notice when you step away, it reads only the number of seconds since your last keyboard or mouse input.

Everything it writes

  • Reminder log
    ~/Library/Application Support/DeskBreak/
  • Settings and timer state
    ~/Library/Preferences/io.github.ananthanarayanan431.deskbreak.plist
  • Login item, if you turn it on
    System Settings, General, Login Items

Install

Run these in Terminal.

brew tap ananthanarayanan431/tap
brew install deskbreak
open "$(brew --prefix)/opt/deskbreak/DeskBreak.app"

Then, once

  1. Open DeskBreak's Settings from the drop icon and turn on Launch at login.
